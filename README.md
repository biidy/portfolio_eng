## 9. ORIENT'IA – Intelligent Academic Guidance Assistant (Group Project)

**Context:** Development of an intelligent assistant that supports students in their academic guidance, based on available information about programs, tracks, and curricula.

🔗 **[Source Code (GitHub)](https://github.com/adriantsoaa/OrientIA-codeA-back)**

* **Objectives:** Make it easier to find academic information, answer students' questions, and offer personalized guidance based on their profiles and the available data.

* **Skills gained:** Designing a RAG system, document processing and semantic search, integrating large language models (LLMs), vector databases, and developing intelligent assistants.
